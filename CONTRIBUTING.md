Obrigado por querer melhorar o curso! Toda contribuição é bem-vinda.

Você pode contribuir com a correção de um comando que mudou de versão, erro de digitação na
apostila, melhoria em um desafio, ou um print de app rodando.

# Como contribuir

1. Abra uma _Issue_ primeiro (se a mudança for grande). Assim a gente
   conversa antes e evita trabalho duplicado.
2. _Fork_ + _Pull Request_ para mudanças em texto, código ou apostila.
3. Para erros pequenos (typo, link quebrado), uma _Issue_ sozinha já basta.

# Regras rápidas

- Para os códigos `.bas`, teste no celular antes de enviar. 
- Edite só os arquivos em `docs/aulas/src/`
- O PDF é gerado automaticamente pela _GitHub Action_.
- Os nomes de arquivos `.bas` deve estar em ASCII sem espaços, numerados com zero à esquerda (`01-`, `02-`…).

# Código de conduta

Seja gentil. Este repositório existe para que mais gente descubra que
pode programar com o que já está no bolso.
